# Manage the documents list and order

Let each user search and reorder their own document list. These preferences belong to the current browser and must not affect other users or the shared Yjs rooms.

## Requirements

- Persist the document list, custom order, and titles in the current browser.
- Allow users to reorder documents with drag and drop.
- Keep order and search preferences local to the current user; these actions must not update shared document data.
- Put newly created or newly opened (subscribed) documents at the top of the list by default.
- Add a search field that filters this browser's document list by title.
